## 🧩 Naming Convention

**Directory:**  
```
docs/context/
```

**Template File:**  
```
docs/context/session_recap_template.md
```

**Format for Session Files:**  
```
docs/context/session_[YYYY-MM-DD-HHMM]_[AGENT]_[KEY-ACTION].md
```

**Examples:**  
- `docs/context/session_2025-10-30-1420_athena_docker-foundation.md`  
- `docs/context/session_2025-10-30-1530_architect_architecture-sync.md`  
- `docs/context/session_2025-10-30-1600_valhalla_repo-reorg.md`

**Purpose:**  
Readable audit trail with immediate clarity on *who*, *when*, and *what the hell happened.*
