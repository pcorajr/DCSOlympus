BFIS Chat Interface Test

Capabilities

  • Query Battlefield: Ask about current situation, unit counts, threats
  • Unit Information: Query specific units by coalition, category, or zone
  • Recent Changes: Check what changed since last query
  • Action Proposals: Request actions (spawn, move, attack) - requires approval

Endpoints

  • POST /bfis/chat/message - Send message
  • POST /bfis/chat/approve - Approve/reject actions
  • GET /bfis/chat/history - Get conversation history
